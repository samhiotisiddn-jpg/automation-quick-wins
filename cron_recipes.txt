CRON RECIPES — the autonomy layer
==================================
Install:  crontab -e   (then paste the lines below)
Verify:   crontab -l

# 1. Money ping — every 5 minutes
*/5 * * * * $HOME/payment_ping.sh >> $HOME/money.log 2>&1

# 2. Process watchdog — every 15 minutes
*/15 * * * * $HOME/watchdog.sh >> $HOME/watchdog.log 2>&1

# 3. Inbox intent sort — hourly at 7 past
7 * * * * python3 $HOME/reply_sorter.py you@gmail.com app_password >> $HOME/leads.log 2>&1

NOTES
-----
* Cron has no PATH — always use absolute paths in real usage.
* Test each script by hand BEFORE cronning it: bash -x script.sh
* On Android: this exact trio runs under Termux with the `cronie` package.
  Keep the phone plugged in, disable battery optimization for Termux,
  and on Android 12+ run once via adb:
    adb shell "settings put global settings_enable_monitor_phantom_procs false"
* Silence means green. Only failures should ever message you.
